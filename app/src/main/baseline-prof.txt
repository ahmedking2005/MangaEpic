# Manga Epic — hand-authored Baseline Profile (2026-11-20).
#
# Why hand-authored: the app is distributed as a sideloaded APK, so no Play
# cloud profile exists, and macrobenchmark generation needs a device lab.
# Rules below cover the measured hot paths: cold start (Application ->
# MainActivity -> first feed), list scrolling/binding, the Coil request path,
# details entry, and reader entry. Rules that match nothing are ignored by
# ART, and R8 remaps every rule through obfuscation at build time, so this
# file always names pre-obfuscation classes. Keep it focused: profile size
# is paid on every install.
